📚 Коллекции в Java

Коллекции — основа работы с данными. На собесе спросят иерархию, отличия реализаций и устройство HashMap.

Иерархия коллекций

Iterable
 └── Collection
      ├── List (по индексу, дубликаты ✅)
      │    ├── ArrayList (массив)
      │    ├── LinkedList (двусвязный список)
      │    └── Vector (устаревший, synchronized)
      ├── Set (уникальные, дубликаты ❌)
      │    ├── HashSet (нет порядка, O(1))
      │    ├── LinkedHashSet (порядок вставки)
      │    └── TreeSet (сортировка, O(log n))
      └── Queue (FIFO)
           ├── LinkedList
           └── PriorityQueue (по приоритету)

Map (НЕ от Collection, отдельно)
 ├── HashMap (нет порядка, O(1))
 ├── LinkedHashMap (порядок вставки)
 ├── TreeMap (сортировка по ключам, O(log n))
 └── Hashtable (устаревший, synchronized)

get(i)⚡ O(1)🐢 O(n)

ArrayList — динамический массив, быстрый доступ O(1), медленная вставка в середину O(n). LinkedList — двусвязный список, медленный доступ O(n), быстрая вставка в середину O(1). В большинстве случаев ArrayList.

Способы обхода коллекций

// List — 4 способа
List<String> list = List.of("A", "B", "C");

// 1. for-each (самый читаемый)
for (String s : list) { System.out.println(s); }

// 2. По индексу
for (int i = 0; i < list.size(); i++) { System.out.println(list.get(i)); }

// 3. Iterator
Iterator<String> it = list.iterator();
while (it.hasNext()) { System.out.println(it.next()); }

// 4. Stream / forEach
list.forEach(System.out::println);

// Map — 3 способа
Map<String, Integer> map = Map.of("A", 1, "B", 2);

// 1. По ключам
for (String key : map.keySet()) { System.out.println(key + "=" + map.get(key)); }

// 2. По entry (самый эффективный)
for (Map.Entry<String, Integer> entry : map.entrySet()) {
    System.out.println(entry.getKey() + "=" + entry.getValue());
}

// 3. forEach
map.forEach((k, v) -> System.out.println(k + "=" + v));

HashMap — как устроен внутри

Массив корзин (buckets). Каждая корзина — связный список → красно-чёрное дерево при 8+.

put(K, V):

  1. hashCode() ключа → индекс корзины
  2. Корзина пуста → кладём пару
  3. Корзина занята → идём по списку, сравниваем через equals()
  4. Ключ совпал → перезапись, не совпал → добавляем в конец
  5. Список > 8 → красно-чёрное дерево

Сложность: средняя O(1), худшая O(n) при плохом hashCode (всё в одной корзине).

HashMap — массив корзин. put(): хэш ключа → корзина → сравнение equals(). Коллизия: идём по связному списку. Сложность O(1) в среднем. Ключи должны быть immutable.

HashSet — внутри HashMap!

// Упрощённо:
public class HashSet<E> {
    private HashMap<E, Object> map;
    private static final Object PRESENT = new Object();

    public boolean add(E e) {
        return map.put(e, PRESENT) == null;
    }
}

Важные нюансы

  • Ключи HashMap — immutable (иначе изменится hashCode и объект потеряется)
  • ConcurrentModificationException — если менять коллекцию во время итерации (кроме iterator.remove())
  • Collections.unmodifiableList() — неизменяемая обёртка
  • List.of() / Set.of() (Java 9+) — неизменяемые коллекции

Утилитный класс Collections — синтаксис и примеры

java.util.Collections — набор статических методов для работы с коллекциями.

Сортировка

List<String> list = new ArrayList<>(List.of("C", "A", "B"));

// Natural order (естественный порядок — Comparable)
Collections.sort(list);                     // [A, B, C]

// С компаратором (по длине строки)
Collections.sort(list, (a, b) -> Integer.compare(a.length(), b.length()));

// Сортировка в обратном порядке
Collections.sort(list, Collections.reverseOrder());

// Сортировка с компаратором в обратном порядке
Collections.sort(list, Comparator.comparing(String::length).reversed());

Перемешивание и переворот

Collections.shuffle(list);               // случайное перемешивание
Collections.shuffle(list, new Random(42)); // с заданным Random (воспроизводимо)
Collections.reverse(list);                 // перевернуть порядок [C, B, A]

Поиск

// Бинарный поиск — список ДОЛЖЕН быть отсортирован!
Collections.sort(list);                    // сначала сортируем
int index = Collections.binarySearch(list, "B"); // 1

// Если элемент не найден — возвращает отрицательное значение:
// -(insertion point) - 1
int notFound = Collections.binarySearch(list, "Z"); // -4 (должен быть на 3-й позиции)

Min / Max

String min = Collections.min(list);                  // natural order
String max = Collections.max(list);                  // natural order
String minByLen = Collections.min(list, Comparator.comparing(String::length));
String maxByLen = Collections.max(list, Comparator.comparing(String::length));

Частота и замена

List<String> names = List.of("A", "B", "A", "C", "A");

// Сколько раз встречается
int freq = Collections.frequency(names, "A"); // 3

// Заменить все вхождения
List<String> mutable = new ArrayList<>(names);
Collections.replaceAll(mutable, "A", "X");     // [X, B, X, C, X]

Заполнение и копирование

// Заполнить список одним значением
List<String> list = new ArrayList<>(Arrays.asList("", "", ""));
Collections.fill(list, "default");            // [default, default, default]

// Копирование (назначение должно быть НЕ МЕНЬШЕ источника)
List<String> src = List.of("X", "Y", "Z");
List<String> dst = new ArrayList<>(Arrays.asList("", "", "", ""));
Collections.copy(dst, src);                   // dst = [X, Y, Z, ""] (последний не перезаписан)

Неизменяемые обёртки (Unmodifiable)

List<String> original = new ArrayList<>(List.of("A", "B", "C"));

// Создать неизменяемое представление (view — следит за оригиналом!)
List<String> unmodifiable = Collections.unmodifiableList(original);

// unmodifiable.add("D"); // ❌ UnsupportedOperationException!
// original.add("D");     // ✅ Меняем оригинал → unmodifiable тоже изменился!

// Полностью независимая копия
List<String> copy = new ArrayList<>(original); // независимый список

// Java 9+ — по-настоящему неизменяемые коллекции
List<String> immutable = List.of("A", "B", "C"); // вообще нельзя менять
Set<String> immutableSet = Set.of("A", "B", "C");
Map<String, Integer> immutableMap = Map.of("A", 1, "B", 2);

Синхронизированные обёртки (Synchronized)

// Обычный список — не потокобезопасный
List<String> list = new ArrayList<>();

// Синхронизированная обёртка
List<String> syncList = Collections.synchronizedList(list);

// При итерации нужно явно синхронизировать!
synchronized (syncList) {
    for (String s : syncList) {
        System.out.println(s);
    }
}

// Лучше использовать ConcurrentHashMap и CopyOnWriteArrayList
// вместо синхронизированных обёрток

Пустые коллекции

// Вместо return null — возвращай пустую коллекцию
List<String> emptyList = Collections.emptyList(); // неизменяемый
Set<String> emptySet = Collections.emptySet();
Map<String, Integer> emptyMap = Collections.emptyMap();

Singleton (коллекция из одного элемента)

Set<String> single = Collections.singleton("единственный");
List<String> singleList = Collections.singletonList("один");
Map<String, Integer> singleMap = Collections.singletonMap("key", 42);
// Все неизменяемые!
