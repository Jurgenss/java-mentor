🔗 Как всё связано в реальном проекте

Клиент (браузер, мобилка)
        ↓ HTTP/JSON
   Spring MVC (@RestController)
        ↓
   Service Layer (@Service, @Transactional)
        ↓               ↓
 Spring Data JPA    Redis (кеш)
        ↓
   Hibernate
        ↓ JDBC
   PostgreSQL
        ↓
   Flyway (миграции)

Async:
 Service → Kafka → другой сервис/consumer

Инфра:
 Docker Compose (app + postgres + redis + kafka)
 CI/CD (GitHub Actions): push → test → build → deploy
