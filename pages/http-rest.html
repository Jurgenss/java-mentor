🌐 HTTP и REST

HTTP — протокол, на котором построен весь веб. REST — архитектурный стиль для API. Спрашивают на каждом собесе на backend-джуна.

Идемпотентность:

Метод идемпотентный, если повторный вызов не меняет результат. Пример: сколько раз ни вызови GET /users/1 — результат тот же. А POST /users при каждом вызове создаёт нового пользователя.

Основные HTTP-методы: GET (получить), POST (создать), PUT (заменить), PATCH (частично обновить), DELETE (удалить). Идемпотентные: GET, PUT, DELETE (повторный вызов не меняет результат). Неидемпотентные: POST, PATCH.

REST — архитектурный стиль

REST (Representational State Transfer) — набор принципов для построения API.

Принципы REST:

  1. Клиент-сервер — клиент и сервер независимы
  2. Stateless — каждый запрос содержит всю информацию, сервер не хранит состояние клиента
  3. Кеширование — ответы можно кешировать
  4. Единый интерфейс — ресурсы через URI, стандартные методы
  5. Многослойность — клиент не знает, общается с сервером или прокси

Правила именования REST API:

✅ Правильно:
GET    /api/users          // получить всех пользователей
GET    /api/users/123      // получить одного
POST   /api/users          // создать
PUT    /api/users/123      // обновить целиком
PATCH  /api/users/123      // частично обновить
DELETE /api/users/123      // удалить
GET    /api/users/123/orders // заказы пользователя

❌ Неправильно:
GET    /api/getAllUsers    // глаголы в URL
POST   /api/createUser     // глаголы
GET    /api/users?id=123   // параметр вместо пути (для одиночного ресурса)

Создание REST API на Spring Boot

@RestController
@RequestMapping("/api/users")
public class UserController {

    @Autowired
    private UserService userService;

    @GetMapping
    public List<User> getAll() {
        return userService.findAll();
    }

    @GetMapping("/{id}")
    public User getById(@PathVariable Long id) {
        return userService.findById(id);
    }

    @PostMapping
    @ResponseStatus(HttpStatus.CREATED)
    public User create(@RequestBody @Valid User user) {
        return userService.create(user);
    }

    @PutMapping("/{id}")
    public User update(@PathVariable Long id, @RequestBody @Valid User user) {
        return userService.update(id, user);
    }

    @DeleteMapping("/{id}")
    @ResponseStatus(HttpStatus.NO_CONTENT)
    public void delete(@PathVariable Long id) {
        userService.delete(id);
    }
}
