🔐 Модификаторы доступа в Java

Модификаторы определяют, откуда можно обратиться к полю, методу или классу. Всего их четыре.

Четыре модификатора

МодификаторВидимостьПример
private Только внутри своего класса private int age;
default (без слова) Внутри своего пакета int age; (просто без модификатора)
protected Внутри пакета + наследники в любом пакете protected int age;
public Везде (любой класс) public int age;

Запоминалка: "Private → Package → Protected → Public" — по возрастанию доступности.

В Java четыре модификатора доступа: private (только внутри класса), default или package-private (внутри пакета), protected (пакет + наследники), public (везде). Чем меньше доступности, тем лучше инкапсуляция.

private — самый строгий

Доступ только внутри того же класса. Основа инкапсуляции.

public class Person {
    private int age; // никто снаружи не видит

    public Person(int age) {
        this.age = age; // внутри класса — можно
    }

    private void secretMethod() {
        System.out.println("Никто не узнает");
    }

    public int getAge() {
        return age; // геттер — публичный доступ к приватному полю
    }
}

// В другом классе:
Person p = new Person(25);
// p.age = 30;        // ❌ Ошибка! private
// p.secretMethod();  // ❌ Ошибка! private
int a = p.getAge();   // ✅ Через публичный геттер

default (package-private) — без слова

Если не написал модификатор — это default. Видно только внутри того же пакета.

// Файл: package com.example;
public class User {
    String name; // default — видно в com.example
    int id;      // default
}

// Файл: package com.example; (тот же пакет)
public class UserService {
    void printUser(User u) {
        System.out.println(u.name); // ✅ Видно — тот же пакет
    }
}

// Файл: package com.other; (другой пакет)
public class OtherService {
    void printUser(User u) {
        // System.out.println(u.name); // ❌ Не видно!
    }
}

Важно: default нельзя написать явно (default int age; — ошибка). Это ключевое слово для switch-блоков и default-методов в интерфейсах.

protected — пакет + наследники

Видно в том же пакете + наследникам из любого пакета.

// Файл: package com.parent;
public class Parent {
    protected String familyName = "Ивановы";

    protected void familySecret() {
        System.out.println("Семейный секрет");
    }
}

// Файл: package com.child; (другой пакет!)
public class Child extends Parent {
    public void reveal() {
        System.out.println(familyName); // ✅ Видно наследнику
        familySecret();                 // ✅ Видно наследнику
    }
}

// Файл: package com.other; (другой пакет, не наследник)
public class Stranger {
    void peek(Parent p) {
        // p.familySecret(); // ❌ Не видно — другой пакет, не наследник
    }
}

Нюанс: protected в наследнике из другого пакета доступен только через ссылку наследника, не через ссылку родителя.

public class Child extends Parent {
    public void test() {
        Child c = new Child();
        c.familySecret(); // ✅ Через ссылку Child

        Parent p = new Child();
        // p.familySecret(); // ❌ Через ссылку Parent — не видно!
    }
}

public — полный доступ

Видно отовсюду. Используй для API — методов, которые должны быть доступны всем.

public class Calculator {
    public int sum(int a, int b) { // доступен везде
        return a + b;
    }
}

Модификаторы для классов

Для внешнего класса — только public или default. private и protected — только для внутренних классов.

public class Outer { }     // ✅ Видно везде
class PackageOnly { }        // ✅ Только в этом пакете
// private class Nope { }    // ❌ Нельзя для внешнего!
// protected class Nope { }  // ❌ Нельзя для внешнего!

public class Outer {
    private class Inner { }  // ✅ Внутренний — можно private
}
