💜 Kotlin для Java-разработчика

Kotlin — современный язык от JetBrains. На 100% совместим с Java (компилируется в тот же байт-код). Лаконичнее Java на 30-40%. Spring официально поддерживает Kotlin.

Java vs Kotlin — первое впечатление

// Java
public class User {
    private String name;
    private int age;

    public User(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    public int getAge() { return age; }
    public void setAge(int age) { this.age = age; }

    @Override
    public String toString() {
        return "User{name='" + name + "', age=" + age + "}";
    }
}

// Kotlin — ВСЁ ТО ЖЕ САМОЕ в одну строку!
data class User(val name: String, val age: Int)
// data class автоматически даёт: конструктор, геттеры, сеттеры (для var),
// equals(), hashCode(), toString(), copy()
Kotlin — современный JVM-язык от JetBrains. Полностью совместим с Java: можно вызывать Kotlin из Java и наоборот. Код на Kotlin на 30-40% короче. Главные фичи: null safety, data class, extension functions, coroutines. Spring Boot официально поддерживает Kotlin.

val vs var — неизменяемые и изменяемые переменные

val name = "Иван"       // val = final в Java (нельзя переприсвоить)
// name = "Пётр"        // ❌ Ошибка!

var age = 25            // var = обычная переменная (можно менять)
age = 26                // ✅

// Тип выводится автоматически, но можно указать явно
val city: String = "Москва"
val count: Int = 42

// ВСЁ — объекты (нет примитивов), но компилятор оптимизирует в int/long

Null Safety — главная фишка Kotlin

Типы делятся на nullable и non-null. Компилятор не даст допустить NullPointerException.

var name: String = "Иван"   // non-null — не может быть null
// name = null                // ❌ Ошибка компиляции!

var nickname: String? = null // nullable — может быть null (знак вопроса!)
nickname = "Ваня"            // ✅
nickname = null              // ✅

// Безопасный вызов (?.) — выполнится только если не null
println(nickname?.length)    // null (не краш!)

// Оператор "Элвис" (?:) — значение по умолчанию если null
val len = nickname?.length ?: 0  // если null → 0

// Утверждение "я уверен, что не null" (!!) — опасно!
val forced = nickname!!.length  // краш если null! Аналог Java-поведения

Функции — компактный синтаксис

// Обычная функция
fun sum(a: Int, b: Int): Int {
    return a + b
}

// Однострочная функция (return не нужен)
fun sumShort(a: Int, b: Int) = a + b

// Параметры по умолчанию (в Java такого нет!)
fun greet(name: String = "Гость", greeting: String = "Привет") {
    println("$greeting, $name!")
}

greet()                     // Привет, Гость!
greet("Иван")              // Привет, Иван!
greet(greeting = "Здравствуй", name = "Мария") // Именованные аргументы

// Строковые шаблоны ($)
val name = "Мир"
println("Привет, $name!")           // Привет, Мир!
println("Сумма: ${sum(2, 3)}")      // Сумма: 5

Классы и data class

// Обычный класс
class Person(val name: String, var age: Int) {
    fun introduce() = "Меня зовут $name, мне $age лет"
}

// data class — автоматически equals, hashCode, toString, copy
data class User(val id: Long, val name: String, val email: String)

val user1 = User(1, "Иван", "ivan@mail.ru")
val user2 = User(1, "Иван", "ivan@mail.ru")
println(user1 == user2)  // true (сравнение по значению, не по ссылке!)
println(user1)           // User(id=1, name=Иван, email=ivan@mail.ru)

// copy — копия с изменениями
val updated = user1.copy(name = "Пётр") // User(id=1, Пётр, ivan@mail.ru)

Extension Functions — расширение существующих классов

Можно добавить метод к ЛЮБОМУ классу, даже если у тебя нет его исходников!

// Добавляем метод repeat к String
fun String.repeat(n: Int): String {
    val sb = StringBuilder()
    for (i in 1..n) sb.append(this)
    return sb.toString()
}

println("Java".repeat(3)) // JavaJavaJava

// Добавляем метод isEven к Int
fun Int.isEven() = this % 2 == 0

println(10.isEven()) // true
println(7.isEven())  // false

// В Java это выглядело бы как StringUtils.repeat(str, n)
// В Kotlin — прямо на объекте: str.repeat(n)

when — улучшенный switch

// Kotlin
val result = when (x) {
    1 -> "один"
    2, 3 -> "два или три"
    in 4..10 -> "от 4 до 10"
    else -> "что-то другое"
}

// when без аргумента — замена цепочки if-else
val description = when {
    age < 18 -> "ребёнок"
    age in 18..65 -> "взрослый"
    else -> "пенсионер"
}

Coroutines — асинхронность без боли

Аналог CompletableFuture/WebFlux в Java, но намного проще. Код выглядит как синхронный, а работает асинхронно.

// Kotlin + coroutines
suspend fun fetchUser(id: Long): User {
    delay(1000) // неблокирующая пауза (поток не спит!)
    return User(id, "Иван", "ivan@mail.ru")
}

suspend fun fetchOrders(userId: Long): List {
    delay(500)
    return listOf(Order(1, 100.0), Order(2, 200.0))
}

// Запуск: как будто синхронный код, но выполняется асинхронно!
runBlocking {
    val user = async { fetchUser(1) }
    val orders = async { fetchOrders(1) }
    println(user.await())  // ждём результат
    println(orders.await())
}

// В Java аналогичное:
// CompletableFuture user = CompletableFuture.supplyAsync(() -> fetchUser(1));
// CompletableFuture> orders = CompletableFuture.supplyAsync(() -> fetchOrders(1));
// user.thenCombine(orders, (u, o) -> ...) — гораздо сложнее!

Kotlin + Spring Boot

// Spring Boot отлично работает с Kotlin!
@RestController
@RequestMapping("/api/users")
class UserController(
    private val userService: UserService  // конструкторная инъекция
) {
    @GetMapping
    fun getAll(): List = userService.findAll()

    @GetMapping("/{id}")
    fun getById(@PathVariable id: Long): User =
        userService.findById(id) ?: throw ResponseStatusException(HttpStatus.NOT_FOUND)

    @PostMapping
    @ResponseStatus(HttpStatus.CREATED)
    fun create(@RequestBody @Valid user: CreateUserRequest): User =
        userService.create(user)
}
