🎯 Лямбды и функциональные интерфейсы

Лямбды появились в Java 8 и полностью изменили стиль написания кода. Теперь это база.

Что такое лямбда-выражение

Лямбда — это компактный способ передать поведение (функцию) как параметр. Замена анонимным классам с одним методом.

// Было — анонимный класс (громоздко)
Runnable r1 = new Runnable() {
    @Override
    public void run() {
        System.out.println("Привет!");
    }
};

// Стало — лямбда (компактно)
Runnable r2 = () -> System.out.println("Привет!");
Лямбда — компактный способ передать функцию как параметр. Заменяет анонимный класс с одним методом. Синтаксис: (параметры) -> { тело }.

Синтаксис лямбда-выражений

ФормаСинтаксисПример
Без параметров () -> действие () -> System.out.println("Hi")
Один параметр x -> действие x -> x * 2
Несколько параметров (a, b) -> действие (a, b) -> a + b
С типами (int a, int b) -> a + b Типы можно опускать
Блок кода (a, b) -> { return a + b; } Если > 1 строки или return 
// Когда скобки и return можно опустить:
x -> x * 2              // один параметр, одно выражение — без скобок и return

// Когда нужны скобки и return:
(x, y) -> {             // несколько параметров
    int sum = x + y;    // несколько строк
    return sum * 2;     // нужен return
}

// С типами (обычно избыточно, но бывает нужно для разрешения неоднозначности)
(int x, int y) -> x + y

Функциональный интерфейс

Функциональный интерфейс — интерфейс с ровно одним абстрактным методом (SAM — Single Abstract Method).

@FunctionalInterface  // аннотация — необязательна, но защищает от ошибок
public interface Calculator {
    int calculate(int a, int b); // один абстрактный метод
}

// Использование с лямбдой:
Calculator sum = (a, b) -> a + b;
Calculator mult = (a, b) -> a * b;

System.out.println(sum.calculate(3, 5));  // 8
System.out.println(mult.calculate(3, 5)); // 15

@FunctionalInterface — аннотация, которая:

  • Проверяет, что в интерфейсе ровно один абстрактный метод
  • Сигнализирует другим разработчикам: "этот интерфейс для лямбд"
  • default и static методы — не считаются (они уже с телом)

Основные функциональные интерфейсы (java.util.function)

ИнтерфейсМетодОписаниеПример лямбды
Predicate<T> boolean test(T t) Проверка условия (фильтр) x -> x > 0
Consumer<T> void accept(T t) Действие над объектом x -> System.out.println(x)
Supplier<T> T get() Поставщик (без параметров) () -> new Random().nextInt()
Function<T,R> R apply(T t) Преобразование T в R x -> x.toString()
UnaryOperator<T> T apply(T t) Function где вход = выход x -> x * 2
BinaryOperator<T> T apply(T a, T b) Бинарная операция (a, b) -> a + b
BiFunction<T,U,R> R apply(T t, U u) Function с двумя параметрами (s, n) -> s + n
BiPredicate<T,U> boolean test(T t, U u) Predicate с двумя параметрами (a, b) -> a > b
BiConsumer<T,U> void accept(T t, U u) Consumer с двумя параметрами (k, v) -> print(k, v)

Примеры использования:

Predicate<String> isEmpty = String::isEmpty;
boolean b = isEmpty.test(""); // true

Consumer<String> printer = System.out::println;
printer.accept("Привет"); // выведет "Привет"

Supplier<LocalDate> today = LocalDate::now;
LocalDate date = today.get();

Function<String, Integer> length = String::length;
int len = length.apply("Java"); // 4

UnaryOperator<Integer> twice = x -> x * 2;
int result = twice.apply(5); // 10

BinaryOperator<Integer> sum = (a, b) -> a + b;
int total = sum.apply(3, 5); // 8

Method Reference (ссылки на методы)

Ещё более краткая запись лямбды, когда лямбда просто вызывает существующий метод.

ТипСинтаксисЛямбдаMethod Reference
Статический метод Class::staticMethod x -> Math.abs(x) Math::abs
Метод объекта obj::method x -> printer.print(x) printer::print
Метод класса (1-й параметр — this) Class::method s -> s.toLowerCase() String::toLowerCase
Конструктор Class::new () -> new ArrayList<>() ArrayList::new 
// Примеры Method Reference
List<String> names = List.of("анна", "иван", "пётр");

// Статический метод
names.stream().map(String::toUpperCase)  // s -> s.toUpperCase()
    .forEach(System.out::println);       // s -> System.out.println(s)

// Конструктор
Supplier<List<String>> listSupplier = ArrayList::new; // () -> new ArrayList<>()

// Сортировка с компаратором через Method Reference
List<Person> people = ...;
people.sort(Comparator.comparing(Person::getName)); // p -> p.getName()

Композиция функций (andThen, compose, negate, or)

// Function: andThen (после) и compose (до)
Function<String, String> upper = String::toUpperCase;
Function<String, String> exclaim = s -> s + "!";

Function<String, String> shout = upper.andThen(exclaim);
shout.apply("java"); // "JAVA!"

Function<String, String> exclaimUpper = exclaim.compose(upper);
exclaimUpper.apply("java"); // "JAVA!"

// Predicate: and, or, negate
Predicate<String> notEmpty = s -> !s.isEmpty();
Predicate<String> startsWithJ = s -> s.startsWith("J");

Predicate<String> notEmptyAndStartsWithJ = notEmpty.and(startsWithJ);
notEmptyAndStartsWithJ.test("Java"); // true
notEmptyAndStartsWithJ.test("");     // false

Predicate<String> isNullOrEmpty = s -> s == null || s.isEmpty();
Predicate<String> isNotNullOrEmpty = isNullOrEmpty.negate(); // отрицание

// Consumer: andThen
Consumer<String> print = System.out::print;
Consumer<String> println = System.out::println;
Consumer<String> printAndPrintln = print.andThen(println);
printAndPrintln.accept("Привет"); // "ПриветПривет\n"

Замыкание (closure) и effectively final

Лямбда может захватывать переменные из внешней области видимости, но они должны быть effectively final (не изменяться после присвоения).

String name = "Иван"; // effectively final — не меняется

// ✅ Можно — name не меняется
Runnable r = () -> System.out.println("Привет, " + name);

// ❌ Нельзя — name изменится, перестанет быть effectively final
// name = "Пётр"; // ошибка компиляции в лямбде!
