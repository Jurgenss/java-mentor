🐧 Linux для Java-разработчика

99% серверов работают на Linux. На собесе спросят базовые команды: навигация, права, процессы, логи. Глубокого администрирования не ждут, но "как посмотреть логи" — обязательный вопрос.

Зачем Java-разработчику Linux

  • 🚀 Серверы — твой код запускается на Linux-серверах
  • 📋 Логи — ошибки в проде смотрят через терминал
  • 🐳 Docker — контейнеры основаны на Linux
  • 🔧 Деплой — CI/CD пайплайны выполняют bash-скрипты
  • 📊 Мониторинг — нагрузка, память, диски
Linux — основная ОС для серверов. Девопс-задачи (посмотреть логи, перезапустить сервис, проверить память) выполняются через терминал. Для джуна достаточно знать базовые команды.

Просмотр и поиск в файлах

КомандаЧто делаетПример
cat <file>Вывести весь файлcat app.log
less <file>Просмотр с прокруткой (q — выход)less app.log

tail -100 <file>Последние 100 строкtail -100 app.log
head -20 <file>Первые 20 строк

Пайпы (|) и перенаправление

# Пайп — передать вывод одной команды на вход другой
grep "ERROR" app.log | tail -10       # последние 10 ошибок

# Перенаправление вывода в файл (> — перезаписать, >> — добавить)
java -jar app.jar > app.log 2>&1 &    # запустить и писать логи в файл

# Сортировка и уникальные значения
grep "ERROR" app.log | sort | uniq -c | sort -rn  # топ ошибок по частоте

Права доступа (chmod)

# Просмотр прав
ls -la
# -rwxr-xr--  1 user group  4096 Jun 11 12:00 app.jar
#  ↑  ↑  ↑
#  |  |  └── права для остальных (r-- = только чтение)
#  |  └───── права для группы (r-x = чтение + выполнение)
#  └──────── права владельца (rwx = чтение + запись + выполнение)

# Изменить права
chmod +x script.sh        # сделать исполняемым
chmod 755 app.jar         # rwxr-xr-x (владелец — всё, остальные — чтение+запуск)
chmod 644 config.prop     # rw-r--r--

SSH — подключение к серверу

ssh user@server.com              # подключиться
ssh -p 2222 user@server.com     # нестандартный порт
ssh -i key.pem user@server.com  # с ключом

# Копирование файлов
scp app.jar user@server.com:/opt/myapp/          # на сервер
scp user@server.com:/var/log/app.log ./          # с сервера

Типичные задачи джуна в Linux

# Посмотреть логи приложения
tail -f /var/log/myapp/application.log

# Найти ошибку
grep -A 5 "Exception" application.log | less

# Перезапустить сервис (systemd)
sudo systemctl restart myapp

# Проверить, запущен ли сервис
sudo systemctl status myapp

# Проверить, слушает ли порт 8080
netstat -tlnp | grep 8080
# или
ss -tlnp | grep 8080

# Посмотреть нагрузку
top -p $(pgrep -f myapp)
