1. Палиндром easy ▼

Задача: проверить, читается ли строка одинаково в обоих направлениях (без учёта пробелов и регистра).

Примеры: "казак" → true, "Java" → false, "А роза упала на лапу Азора" → true

✍️ Твоё решение:

public static boolean isPalindrome(String s) { // твой код здесь }
public static boolean isPalindrome(String s) {
    String cleaned = s.replaceAll("[^a-zA-Zа-яА-Я0-9]", "").toLowerCase();
    int left = 0;
    int right = cleaned.length() - 1;
    while (left < right) {
        if (cleaned.charAt(left) != cleaned.charAt(right)) return false;
        left++;
        right--;
    }
    return true;
}

Сложность: O(n), память O(1).

2. Анаграмма easy ▼

Задача: проверить, состоят ли две строки из одинаковых символов (регистр не важен).

Примеры: "listen", "silent" → true, "hello", "world" → false

✍️ Твоё решение:

public static boolean isAnagram(String s1, String s2) { // твой код здесь }
public static boolean isAnagram(String s1, String s2) {
    if (s1.length() != s2.length()) return false;
    s1 = s1.toLowerCase(); s2 = s2.toLowerCase();
    int[] counts = new int[26];
    for (char c : s1.toCharArray()) counts[c - 'a']++;
    for (char c : s2.toCharArray()) counts[c - 'a']--;
    for (int n : counts) if (n != 0) return false;
    return true;
}

Сложность: O(n), память O(1).

3. Разворот строки easy ▼

Задача: перевернуть строку без StringBuilder.reverse().

Пример: "Java" → "avaJ"

✍️ Твоё решение:

public static String reverse(String s) { // твой код здесь }
public static String reverse(String s) {
    char[] chars = s.toCharArray();
    int left = 0, right = chars.length - 1;
    while (left < right) {
        char temp = chars[left];
        chars[left] = chars[right];
        chars[right] = temp;
        left++; right--;
    }
    return new String(chars);
}

Сложность: O(n).

4. Поиск дубликатов easy ▼

Задача: найти все дубликаты в массиве.

Пример: [1, 2, 3, 2, 1, 4] → [1, 2]

✍️ Твоё решение:

public static List<Integer> findDuplicates(int[] arr) { // твой код здесь }
public static List<Integer> findDuplicates(int[] arr) {
    Set<Integer> seen = new HashSet<>();
    Set<Integer> dups = new HashSet<>();
    for (int n : arr) if (!seen.add(n)) dups.add(n);
    return new ArrayList<>(dups);
}

6. Two Sum medium ▼

Задача (LeetCode 1): найти индексы двух чисел, дающих в сумме target.

Пример: nums = [2,7,11,15], target = 9 → [0,1]

✍️ Твоё решение:

public static int[] twoSum(int[] nums, int target) { // твой код здесь }
public static int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> map = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int comp = target - nums[i];
        if (map.containsKey(comp)) return new int[]{map.get(comp), i};
        map.put(nums[i], i);
    }
    throw new IllegalArgumentException("Нет решения");
}

Сложность: O(n).

7. Факториал easy ▼

✍️ Твоё решение:

public static long factorial(int n) { // твой код здесь (итеративно или рекурсивно) }
// Итеративно
public static long factorial(int n) {
    long result = 1;
    for (int i = 2; i <= n; i++) result *= i;
    return result;
}
// Рекурсивно
public static long factorialRec(int n) {
    return n <= 1 ? 1 : n * factorialRec(n - 1);
}

8. Числа Фибоначчи medium ▼

Задача: вернуть n-е число Фибоначчи (0,1,1,2,3,5,8...).

✍️ Твоё решение:

public static long fibonacci(int n) { // твой код здесь }
public static long fibonacci(int n) {
    if (n <= 1) return n;
    long prev = 0, curr = 1;
    for (int i = 2; i <= n; i++) {
        long next = prev + curr;
        prev = curr;
        curr = next;
    }
    return curr;
}

9. Бинарный поиск medium ▼

Задача: найти индекс элемента в отсортированном массиве.

Пример: arr = [1,3,5,7,9], target = 5 → 2

✍️ Твоё решение:

public static int binarySearch(int[] arr, int target) { // твой код здесь }
public static int binarySearch(int[] arr, int target) {
    int left = 0, right = arr.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (arr[mid] == target) return mid;
        else if (arr[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}

Сложность: O(log n).

10. Правильные скобки medium ▼

Задача (LeetCode 20): проверить правильность скобок () [] {}.

Примеры: "()[]{}" → true, "([)]" → false

✍️ Твоё решение:

public static boolean isValid(String s) { // твой код здесь }
public static boolean isValid(String s) {
    Stack<Character> stack = new Stack<>();
    for (char c : s.toCharArray()) {
        if (c == '(' || c == '[' || c == '{') { stack.push(c); }
        else {
            if (stack.isEmpty()) return false;
            char top = stack.pop();
            if (c == ')' && top != '(') return false;
            if (c == ']' && top != '[') return false;
            if (c == '}' && top != '{') return false;
        }
    }
    return stack.isEmpty();
}
